# GUESS-THE-NUMBER
A simple and fun interactive number guessing game built using Python.

## FEATURES
- Generates a random number within a specified range.
- Provides hints (higher/lower) based on the user's guess.
- Tracks the number of attempts taken to guess correctly.
- Simple and clean command-line interface (CLI).

- Make sure python is installed on your computer.
- Download or clone this repository:

  python " guess the number.py"
